# Production Native Server Setup Guide

## Overview

This guide details how to deploy the KM Help Desk application on a traditional Linux server (LEMP Stack). This method provides maximum performance and direct control over the server environment but requires more manual configuration than Docker.

## Architecture

### Services Overview

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Nginx (80/443)│────│   PHP-FPM 8.3   │────│   MySQL 8.0     │
│                 │    │                 │    │                 │
│   - Static files│    │   - Application │    │   - Persistent  │
│   - SSL/TLS     │    │   - Worker      │    │   - Data        │
│   - Reverse Proxy│   │   - Scheduler   │    │                 │
└─────────────────┘    └────────┬────────┘    └─────────────────┘
                                │
                   ┌────────────┴────────────┐
                   │     Redis (Cache)       │
                   │                         │
                   │   - Sessions            │
                   │   - Cache               │
                   │   - Queues              │
                   └─────────────────────────┘
```

## Prerequisites

- **OS:** Ubuntu 22.04 LTS or 24.04 LTS
- **Access:** Root or Sudo user
- **Domain:** A domain name pointing to your server IP
- **RAM:** Minimum 2GB recommended

## 1. Initial Server Setup

We provide an automated script to provision your server with all necessary dependencies (Nginx, PHP 8.3, MySQL, Redis, Node.js, Certbot).

### Automatic Setup (Recommended)

1.  **Upload the setup script** to your server:

    ```bash
    scp setup-server.sh user@your-server-ip:~/
    ```

2.  **Run the script** on the server:
    ```bash
    chmod +x setup-server.sh
    sudo ./setup-server.sh
    ```

### What does the script do?

- Updates system packages
- Installs **Nginx**
- Installs **PHP 8.3** with all required extensions (bcmath, intl, redis, etc.)
- Installs **MySQL 8.0** and runs `mysql_secure_installation`
- Installs **Redis** and sets a password
- Installs **Node.js 20** and **Composer**
- Configures firewall (UFW)
- Tunes PHP-FPM settings for performance

## 2. Application Deployment

### Directory Structure

We recommend deploying to `/var/www/km-help-desk`.

### First-Time Deployment

1.  **Clone the Repository:**

    ```bash
    cd /var/www
    sudo git clone <your-repo-url> km-help-desk
    cd km-help-desk
    ```

2.  **Set Permissions:**

    ```bash
    sudo chown -R www-data:www-data /var/www/km-help-desk
    sudo chmod -R 775 storage bootstrap/cache
    ```

3.  **Configure Environment:**

    ```bash
    cp .env.example .env
    nano .env
    ```

    Update the following:
    - `APP_ENV=production`
    - `APP_URL=https://your-domain.com`
    - `DB_PASSWORD` (User `root` password set during setup)
    - `REDIS_PASSWORD` (Password generated by setup script)

4.  **Install Dependencies:**

    ```bash
    # PHP Dependencies
    composer install --no-dev --optimize-autoloader

    # Frontend Assets
    npm ci
    npm run build
    ```

5.  **Generate Key & Migrate:**
    ```bash
    php artisan key:generate
    php artisan migrate --force
    php artisan storage:link
    ```

## 3. Web Server Configuration

1.  **Copy Nginx Config:**

    ```bash
    sudo cp docker/nginx/production.conf /etc/nginx/sites-available/km-help-desk.conf
    ```

    _Note: You may need to edit this file to update paths if they differ from `/var/www/html`._

2.  **Edit Config:**
    Change `root /var/www/html/public;` to `root /var/www/km-help-desk/public;` inside the file.
    Change `server_name _;` to `server_name your-domain.com;`.
    Update the PHP-FPM socket path to `fastcgi_pass unix:/run/php/php8.3-fpm.sock;`.

3.  **Enable Site:**

    ```bash
    sudo ln -s /etc/nginx/sites-available/km-help-desk.conf /etc/nginx/sites-enabled/
    sudo nginx -t
    sudo systemctl reload nginx
    ```

4.  **SSL Setup:**
    ```bash
    sudo certbot --nginx -d your-domain.com
    ```

## 4. Background Workers (Queue & Schedule)

For production, you must use **Supervisor** to keep your queue workers running.

1.  **Install Supervisor:**

    ```bash
    sudo apt-get install supervisor
    ```

2.  **Configure Queue Worker:**
    Create `/etc/supervisor/conf.d/km-help-desk-worker.conf`:

    ```ini
    [program:km-help-desk-worker]
    process_name=%(program_name)s_%(process_num)02d
    command=php /var/www/km-help-desk/artisan queue:work redis --sleep=3 --tries=3 --max-time=3600
    autostart=true
    autorestart=true
    stopasgroup=true
    killasgroup=true
    user=www-data
    numprocs=2
    redirect_stderr=true
    stdout_logfile=/var/www/km-help-desk/storage/logs/worker.log
    stopwaitsecs=3600
    ```

3.  **Configure Scheduler (Cron):**
    Add the following cron entry (`sudo crontab -e -u www-data`):

    ```bash
    * * * * * cd /var/www/km-help-desk && php artisan schedule:run >> /dev/null 2>&1
    ```

4.  **Start Workers:**
    ```bash
    sudo supervisorctl reread
    sudo supervisorctl update
    sudo supervisorctl start all
    ```

## 5. Ongoing Maintenance

### Using the Deploy Script

We have included a `deploy-server.sh` script to automate updates.

```bash
./deploy-server.sh
```

This script will:

- Enable maintenance mode
- Pull latest code
- Install dependencies
- Build assets
- Run migrations
- Clear cache
- Restart Queue workers and PHP-FPM
- Disable maintenance mode

### Viewing Logs

- **Nginx Access:** `/var/log/nginx/access.log`
- **Nginx Error:** `/var/log/nginx/error.log`
- **Laravel Logs:** `/var/www/km-help-desk/storage/logs/laravel.log`
- **Queue Logs:** `/var/www/km-help-desk/storage/logs/worker.log`

### Security Checklist

- [ ] firewall (UFW) enabled allowing only SSH, HTTP, HTTPS
- [ ] MySQL root remote access disabled
- [ ] Redis password enabled
- [ ] `.env` file permissions set to 600
- [ ] SSH password authentication disabled (use keys)
